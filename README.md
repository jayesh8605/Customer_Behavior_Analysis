# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer shopping behavior using Python, SQL, PostgreSQL, and Power BI. The goal is to explore purchasing patterns, evaluate discount usage, understand customer segments, and identify insights that can support data-driven business decisions.

The project follows an end-to-end data analytics workflow, from data cleaning and preprocessing to SQL-based business analysis and interactive dashboard development.

## Tools & Technologies

- **Python:** Pandas, data cleaning, preprocessing, and exploratory data analysis
- **SQL:** PostgreSQL, aggregate functions, subqueries, CTEs, CASE statements, and window functions
- **Power BI:** Interactive dashboards, KPI cards, slicers, and data visualization
- **Jupyter Notebook:** Python analysis and documentation
- **PostgreSQL:** Data storage and querying

## Dataset

The dataset contains **3,900 customer records and 18 original columns** describing customer demographics, purchases, preferences, and shopping behavior.

Key attributes include:

- Customer ID, age, and gender
- Item purchased and product category
- Purchase amount
- Review rating
- Subscription status
- Shipping type
- Discount and promo code usage
- Previous purchases
- Payment method
- Frequency of purchases

## Project Workflow

### 1. Data Cleaning & Preprocessing — Python

- Loaded the dataset using Pandas.
- Examined descriptive statistics and missing values.
- Filled missing review ratings using the median rating within each product category.
- Standardized column names by converting them to lowercase and replacing spaces with underscores.
- Created age groups using quartile-based binning with `pd.qcut()`.
- Filled missing purchase-frequency day values using the corresponding purchase-frequency category.
- Prepared the cleaned data for loading into PostgreSQL.

### 2. SQL Business Analysis — PostgreSQL

Developed SQL queries to investigate the following business questions:

1. What is the total revenue generated by male and female customers?
2. Which customers used discounts but spent more than the average purchase amount?
3. Which five products have the highest average review ratings?
4. How do average purchase amounts compare between Standard and Express shipping?
5. Do subscribed customers spend more than non-subscribed customers?
6. Which products have the highest percentage of purchases with discounts applied?
7. How can customers be segmented into New, Returning, and Loyal groups?
8. What are the top three most purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each product category?

SQL concepts used include `GROUP BY`, aggregate functions, subqueries, `CASE WHEN`, CTEs, and `ROW_NUMBER()`.

### 3. Interactive Dashboard — Power BI

Developed a Power BI dashboard to explore customer behavior and purchasing trends.

Dashboard components include:

- KPI cards for customer count, average purchase amount, and average review rating
- Category-wise purchase amount analysis
- Customer count by category
- Subscription status breakdown
- Age-group analysis of purchase amount and customer count
- Interactive filters for gender, category, shipping type, and subscription status

These visuals allow users to explore different customer groups and compare purchasing patterns interactively.

## How to Run the Project

### Python Analysis

1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Place the CSV file in the notebook's working directory.
5. Run the notebook cells in order.

Install the main libraries with:

```bash
pip install pandas sqlalchemy psycopg2-binary jupyter
```

### PostgreSQL Analysis

1. Install and start PostgreSQL.
2. Create the required database.
3. Load the cleaned dataset into PostgreSQL.
4. Run the SQL queries against the customer table.

Update database connection settings for your own environment. Do not commit passwords or other credentials.

### Power BI Dashboard

1. Open `Customer_Behavior_Dashboard.pbix` in Power BI Desktop.
2. Configure the data source if prompted.
3. Refresh the data if required.
4. Use the available slicers and visuals to explore the dashboard.
